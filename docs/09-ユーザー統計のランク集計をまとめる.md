# ユーザー統計のランク集計をまとめる

対象: ISUCON13 練習（ISUPipe / Go 参考実装）  
変更ファイル: `go/stats_handler.go` の `getUserStatisticsHandler`（ランク算出部分のみ）  
目的: `GET /api/user/:username/statistics` のランク計算で、全ユーザーに対する N+1（1人2クエリ）を1本の集計 SQL にまとめる。

関連: [チャット引き継ぎ](./10-チャット引き継ぎ.md) の 6.1

## 旧実装

1. `SELECT * FROM users` で全ユーザーを取得
2. 各ユーザーに対して次を2本ずつ実行

```sql
SELECT COUNT(*) FROM users u
INNER JOIN livestreams l ON l.user_id = u.id
INNER JOIN reactions r ON r.livestream_id = l.id
WHERE u.id = ?

SELECT IFNULL(SUM(l2.tip), 0) FROM users u
INNER JOIN livestreams l ON l.user_id = u.id
INNER JOIN livecomments l2 ON l2.livestream_id = l.id
WHERE u.id = ?
```

3. `score := reactions + tips` で `UserRanking` を組み立て、`sort.Sort`（score 昇順、同点は username 昇順）後、対象 username の順位を末尾から数える（変更なし）。

リアクションもチップも無いユーザーは、旧コードでは `GetContext` が行なしとなり reactions / tips は 0 のまま。スコア 0 でランキングに含まれる。

---

## 新実装

`users` を起点に、配信経由のリアクション数・チップ合計をサブクエリで `GROUP BY l.user_id` し、`LEFT JOIN` で全ユーザーを1行ずつ返す。

```sql
SELECT
  u.name AS username,
  IFNULL(rc.reaction_count, 0) AS reactions,
  IFNULL(tc.tip_sum, 0) AS tips
FROM users u
LEFT JOIN (
  SELECT l.user_id, COUNT(*) AS reaction_count
  FROM livestreams l
  INNER JOIN reactions r ON r.livestream_id = l.id
  GROUP BY l.user_id
) rc ON rc.user_id = u.id
LEFT JOIN (
  SELECT l.user_id, IFNULL(SUM(l2.tip), 0) AS tip_sum
  FROM livestreams l
  INNER JOIN livecomments l2 ON l2.livestream_id = l.id
  GROUP BY l.user_id
) tc ON tc.user_id = u.id
```

Go 側は各行で `Score: reactions + tips` とし、以降の `sort.Sort` と順位計算は旧と同じ。
